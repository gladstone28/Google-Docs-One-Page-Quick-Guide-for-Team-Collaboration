Google Docs -- One-Page Quick Guide for Team Collaboration

1.  Upload Your Document

-   Go to https://drive.google.com
-   Click New → File upload
-   Select your Word document
-   Open it in Google Docs

2.  Share the Document

-   Click Share
-   Add email addresses
-   Set permissions: Editor / Commenter / Viewer
-   Click Send

3.  Turn On Change Tracking (Suggesting Mode)

-   Click the pencil icon
-   Select Suggesting
-   Edits will show with names and approval options

4.  Add Comments or Assign Tasks

-   Highlight text
-   Click the comment icon
-   Use @Name to assign tasks

5.  View Edit History

-   File → Version history → See version history
-   Shows who changed what and when

6.  Link Sharing (Optional)

-   Share → Copy link
-   Choose edit/comment/view permissions
