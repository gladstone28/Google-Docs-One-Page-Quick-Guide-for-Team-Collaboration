


Google Docs – One-Page Quick Guide for Team Collaboration
1. Upload Your Document

Go to https://drive.google.com

Click New → File upload

Select your Word document (.doc/.docx)

Double-click the uploaded file to open in Google Docs

2. Share the Document

Click the Share button (top-right)

Type your team members’ email addresses

Set permissions:

Editor – can edit

Commenter – comment only

Viewer – read-only

Click Send

3. Turn On Change Tracking

Google Docs uses Suggesting Mode (similar to Track Changes).

Click the pencil icon at the top-right

Select Suggesting
Now all edits show with:

The editor’s name

Suggested text in green

Options to Accept or Reject

4. Add Comments or Assign Tasks

Highlight text

Click the comment icon (yellow speech bubble)

Type your note

Use @Name to assign comments to a specific person

5. View Edit History

To see all changes in the timeline:

Click File → Version history → See version history
You will see:

Who made each change

A color label for each person

Earlier versions that you can restore anytime

6. Share a Link (Optional)

Click Share → Copy link

Set link permissions:

Anyone with the link can edit

Anyone with the link can comment

Anyone with the link can view

✔ Summary

With Google Docs, your whole team can:

Work on one shared document

Edit together in real time

Track changes using Suggesting Mode

See full edit history

Comment and assign tasks
